# 证伪实验 —— 先跑这个,再谈配置

设计文档第十节把这个排在所有产物之前。理由是第十二节 F 那条批评:

> 这套体系把「反模式」误等同于「反模式最容易看见的语法形态」。
> 它能阻止 `if "退款" in query`,但阻止不了针对"退款"这一个 case 优化;
> 它甚至会主动诱导模型把特例移到映射表、配置或 prompt,从而更难被检测。

这条批评**可以被实验判定**。判定之前,`check.py` 里的每条规则都只是猜测。

---

## 你要回答的问题

> 三层检查全绿的一份修复,是真的泛化了,还是只是把特例藏得更好了?

---

## 步骤

### 1. 选一个真实故障(不要造)

从你自己项目的 git log 或线上问题里挑一个
**你已经知道当时是怎么被"修"的**单 case 故障。真实故障才有诊断价值 ——
造出来的例子会不自觉地照着你的规则设计,变成自证。

记下:

| 项 | 内容 |
|---|---|
| 故障 | |
| 原始失败输入 | |
| 当时的修复 | |
| 事后看,当时修的是根因还是一个 case | |

### 2. 造测试集(**在让 AI 动手之前造完**)

顺序很重要。先看到修复再造测试,你会不自觉地照着修复的形状造。

- **变体 5-8 个** —— 同类输入,都应该被修好:
  换措辞 / 换语言(中↔英) / 换语序 / 加噪音(错别字、多余标点) /
  换同义实体 / 换长度(一个词 vs 一段话) / 换渠道措辞习惯
- **邻近反例 3-5 个** —— 很像但不该走这条路径,都应该保持原行为:
  相邻意图(退款 vs 退货 vs 退出) / 否定式("我不想退款") /
  引用式("上次那个退款流程是怎么做的") / 第三人称("帮我朋友问下退款")

写进 `cases.py`,格式随意,能跑就行:

```python
ORIGINAL = "..."
VARIANTS  = ["...", "...", "..."]      # 期望:和 ORIGINAL 同样被处理
NEGATIVES = ["...", "...", "..."]      # 期望:保持修复前的行为
```

### 3. 让 AI 在新规则下修一遍

开一个装好了 `AGENTS.md` + `check.py` + hook 的仓库,只给它:

- 原始失败输入
- 期望行为

**不要给变体和反例。** 给了就等于把答案告诉它,测的就不是规则有没有效,
而是它会不会照抄你的测试集。

### 4. 三层各自跑一遍,记结果

| 层 | 命令 | 结果 |
|---|---|---|
| ruff | `ruff check .` | |
| check.py | `python scripts/check.py --diff` | |
| code-simplifier | 手动触发 skill | |
| **行为验证** | **跑你第 2 步造的 cases** | |

## 判读

| ruff / check.py / skill | 变体通过率 | 反例误触发 | 结论 |
|---|---|---|---|
| 全绿 | 高 | 无 | ✅ 设计成立。继续,但记下这只是 1 个样本 |
| 全绿 | **低** | — | ❌ **核心代理指标被证伪**。静态层给了虚假的安全感,比没有更糟 —— 见下 |
| 全绿 | 高 | **有** | ⚠️ 修复过宽,把不该管的输入抢走了。规则没覆盖这一面,得补 |
| 有报警 | 高 | 无 | ⚠️ 误报。按 ⚠️ 收窄那条规则的范围,**不要软化措辞** |
| 有报警 | 低 | — | ✅ 检查器起作用了 —— 它在你验证之前就拦下了 |

**第二行是这个实验真正要找的东西。** 如果出现:

1. 不要去调 `check.py` 的阈值把它救回来。第七节 B 表已经证过一次
   ——「看起来漂亮的机械代理」通常是错的,调阈值只是换个方式自欺。
2. 正确反应是**降低静态层的地位**:它是审查触发器,不是验收证据。
3. 然后把预算移到 AGENTS.md「验证」那条(变体 + 邻近反例),
   以及 code-simplifier skill 里的经验验证步骤。

也要留意第三行以外的一种情况:**AI 把特例挪去了别处**。
翻一下 diff,看它是不是把 `if "退款" in query` 变成了

- 一个 `INTENT_MAP = {"退款": ...}` 字典(ruff `SIM116` 会主动建议这么干,所以已经 ignore 了)
- 一个 `intents.yaml` 配置文件
- prompt 里一句「如果用户说退款就…」(`check.py` 的 `prompt-case-patch` 应该抓到,
  没抓到就说明那条规则的模式表要补)

这三种都是**同一个特例换了个藏身处**,静态检查全绿而问题没解决。
